# Healthcare Management System

## Project Description

The Healthcare Management System is a simple web-based application designed to manage basic healthcare services.

## Features

- Doctor Management
- Appointment Booking
- Patient Management
- Hospital Contact Information
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
